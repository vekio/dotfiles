= dotfiles

Personal Fedora workstation configuration managed with
https://www.chezmoi.io/[chezmoi].

== Install

On a new Fedora workstation:

----
curl -fsSL https://git.casta.me/alberto/dotfiles_new/raw/branch/main/bootstrap.sh | bash
----

`bootstrap.sh` installs chezmoi, applies the managed files, and runs
`~/.local/bin/dotfiles-install`. The installer:

* configures Terra and the Brave repository
* installs the DNF and Flatpak package lists
* removes packages known to conflict with the workstation configuration
* installs mise and the tools declared in `~/.config/mise/config.toml`

It intentionally does not run a full `dnf upgrade`.

== Daily use

Apply configuration changes:

----
chezmoi apply
----

Provision missing workstation packages again:

----
dotfiles-install
----

Upgrade tools managed by mise, including the current Node LTS, pnpm and Codex:

----
mise upgrade
# Fish shortcut:
tools-update
----

The mise selectors are deliberately rolling (`lts` or `latest`), but upgrades
are explicit: `chezmoi apply` and `mise install` do not serve as the update
command.

== Repositories

Zed and Starship are installed from Terra; a separate Starship COPR is not
needed. Brave uses its own RPM repository. RPM Fusion is configured only when
running the optional NVIDIA installer.

Terra's official Fedora bootstrap command uses `--nogpgcheck` for the initial
`terra-release` package because the Terra signing key is not installed yet.
The exception is limited to that bootstrap package. `terra-release` then
configures the repository key used for normal package verification.

== Optional machine setup

----
dotfiles-gpg-card-check
dotfiles-nvidia
----

See the documents under `~/.local/share/dotfiles/docs` before making GPG,
YubiKey, LUKS or NVIDIA changes.

== Repository layout

----
bootstrap.sh                         # new-machine entry point
dot_local/bin/                       # extensionless command symlinks
dot_local/share/dotfiles/exact_scripts/ # shell sources with .sh extension
dot_local/share/dotfiles/packages/   # declarative package lists
dot_local/share/dotfiles/docs/       # machine-specific procedures
dot_config/                          # application configuration
----

The `exact_scripts` source directory becomes
`~/.local/share/dotfiles/scripts`. Its `exact_` attribute makes chezmoi remove
obsolete scripts during migration. The files keep their `.sh` extension for
editor tooling, while the symlinks in `~/.local/bin` expose commands without
the extension.
